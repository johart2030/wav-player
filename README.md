# WAV Player

A local soundboard for theatrical effects. The player supports WAV and MP3 audio.

## Install it beside your sound files on Windows

1. Download `Get WAV Player.bat` from this repository and put it beside your audio files.
2. Run it. It downloads the player files into the same folder and leaves your audio files untouched.
3. Run `Run WAV Player.bat` to start the player. Python 3 is required; keep the launcher window open while using the soundboard.

The GitHub Pages version can load audio after you choose files or a folder. Browsers do not let a website scan local folders automatically; the local launcher provides that behavior.
